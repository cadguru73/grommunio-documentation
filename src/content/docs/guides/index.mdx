The **Administration** manual describes grommunio as a system. The guides in
this section are **task-oriented**: each one takes a single component or
operational topic from prerequisites to a verified, working result, with a
verification checklist and a troubleshooting table at the end.

All guides assume a working grommunio installation — the appliance set up as
described in the [Quickstart](/admin/quickstart/), with DNS, TLS and the first
domain and user in place. Start with the
[post-installation checklist](/guides/post-install/) if you have just finished
`grommunio-setup`.
