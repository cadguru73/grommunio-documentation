### Name

grommunio-admin taginfo — Informationen zu Proptags anzeigen

### Zusammenfassung

<strong>grommunio-admin taginfo</strong> TAG \[TAG …\]

### Beschreibung

Zeigt Informationen zu einem Eigenschaftstag an, wie es in der Master-Eigenschaftsliste der Microsoft Exchange-Serverprotokolle definiert ist.  
Beachten Sie, dass die von grommunio verwendeten Eigenschaftsnamen von den in Microsoft definierten Namen abweichen können.

### Optionen

`TAG`  
Dezimal oder hexadezimal (mit dem Präfix „0x“) – Tag-ID oder grommunio-Tag-Name (Glob)
