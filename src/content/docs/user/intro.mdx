This manual helps you work with grommunio every day — reading and sending mail,
keeping your calendar, managing contacts, tasks and notes, chatting and meeting,
and sharing files. grommunio is built on well-established, standards-based
protocols, so if you already know an e-mail client, you will feel at home
quickly; no special training is required.

## Ways to access grommunio

grommunio is a complete communication and collaboration suite — e-mail,
calendaring, contacts, tasks, notes, video meetings, chat and file management.
You can reach it in three ways, and you can mix them freely on the same account:

Because grommunio speaks the standard protocols (Exchange/MAPI, Exchange
ActiveSync, IMAP/SMTP, CalDAV/CardDAV), most clients work with it. Not every
client exposes every grommunio feature, though — **grommunio Web brings all of
them together in one place**, which is why it is the recommended starting point.

## Using this manual

- The **[grommunio Web](/web/)** chapters are the heart of this manual: a
  feature-by-feature guide to the web interface.
- **[grommunio Desk](/user/desk/)** covers the native desktop application.
- **[Connecting other clients](/user/groupware/)** shows how to set up your
  account in Outlook, Apple Mail, Thunderbird and on mobile devices.
- **[Troubleshooting](/user/troubleshooting/)** collects fixes for the issues
  users hit most often.

Screenshots are provided for illustration; the exact appearance may differ
slightly between versions and platforms, but the steps remain the same.

:::note
This documentation does not replace the vendor documentation of third-party
clients (such as Microsoft Outlook or Mozilla Thunderbird). For clients that are
not exclusive to grommunio, also refer to the documentation provided by the
client's vendor.
:::
