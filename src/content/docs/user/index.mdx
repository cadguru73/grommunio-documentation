Welcome! This guide helps you **use grommunio every day** — mail, calendar,
contacts, tasks and notes, chat, video meetings and file sharing — whether you
work in the browser, the desktop app, or your own e-mail client. grommunio is
built on familiar, standards-based protocols, so no special training is needed.
