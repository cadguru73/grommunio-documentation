## Name

gromox-mailq — Local delivery agent queue lister

## Synopsis

<dfn class="gx-param">gromox-mailq</dfn>

## Description

gromox-mailq looks in the queue directory for [delivery-queue(8gx)](/man/delivery-queue-8gx/) and prints the summaries for all queued mail.
