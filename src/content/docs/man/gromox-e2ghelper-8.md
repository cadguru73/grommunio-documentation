## Name

gromox-e2ghelper — Helper program for exchange2grommunio.ps1

## Synopsis

<strong>gromox-e2ghelper</strong> \[<strong>-u</strong> <em>username</em>\] \[<strong>--</strong> <em>pff-args</em>...\]

## Options

<dfn class="gx-param">-u</dfn> <em>emailaddr</em>  
Username of store to import to.

All non-options arguments are passed through to [gromox-pff2mt(8)](/man/gromox-pff2mt-8/).

## Description

e2ghelper is an implementation detail in the exchange2grommunio.ps1 script and not meant to be called directly.
